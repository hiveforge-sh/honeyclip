<task type="auto">
  <name>Task 1: Create face detection types and consensus algorithm</name>
  <files>src/analyze/faces.nim</files>
  <action>
Create src/analyze/faces.nim with:

1. **FaceDetection type** extending FaceRect:
   - All FaceRect fields (x, y, width, height, confidence, angle)
   - frameIndex: int64 - which frame this detection came from
   - stable: bool - whether consensus considers this face stable

2. **FrameFaces type** for grouping detections per frame:
   - frameIndex: int64
   - timestamp: float64 (in seconds)
   - faces: seq[FaceDetection]

3. **FaceConsensus object** for temporal filtering:
   - window: seq[seq[FaceDetection]] - sliding window of frame detections
   - windowSize: int - configurable (default 3)
   - threshold: float - consensus ratio (default 0.6)
   - minFaceRatio: float - minimum face height as ratio of frame (default 0.05)

4. **Core procs**:
   - `newFaceConsensus*(windowSize: int = 3, threshold: float = 0.6, minFaceRatio: float = 0.05): FaceConsensus`
   - `addFrame*(fc: var FaceConsensus, faces: seq[FaceDetection])` - adds frame, maintains window size
   - `iou(a, b: FaceDetection): float` - Intersection over Union for matching faces across frames
   - `getStableFaces*(fc: FaceConsensus): seq[FaceDetection]` - returns faces appearing in threshold% of frames
   - `filterBySize(faces: seq[FaceDetection], frameHeight: int, minRatio: float): seq[FaceDetection]` - removes small faces

5. **Detection wrapper**:
   - `detectFaces*(imageData: ptr uint8, width, height, stride: int, frameIndex: int64, minConfidence: float = 0.3): seq[FaceDetection]`
   - Calls facedetect.detect(), wraps results in FaceDetection with confidence filter

**Key implementation details:**
- IoU calculation: intersection_area / union_area, where intersection = overlap rect, union = a + b - intersection
- Consensus matching: For each face in current frame, find best IoU match in previous frames (IoU > 0.5 = same face)
- Count appearances across window, mark stable if count/windowSize >= threshold
- Default confidence filter 0.3 (higher than libfacedetection default 0.02 per RESEARCH)

<task type="auto">
  <name>Task 2: Create binary face cache module</name>
  <files>src/facecache.nim</files>
  <action>
Create src/facecache.nim following src/cache.nim pattern:

1. **Cache types**:
   ```nim
   type
     CachedFace* = object
       x*, y*, width*, height*: uint16  # Sufficient for 4K (max 65535)
       confidence*: float32
       angle*: int16
       stable*: bool

     FaceCacheEntry* = object
       frameIndex*: uint32
       timestamp*: float32  # seconds
       faces*: seq[CachedFace]
   ```

2. **Cache key generation** (reuse pattern from cache.nim):
   ```nim
   proc faceProcTag(path: string, tb: AVRational, args: string): string =
     # Same pattern as procTag but with "faces" kind built-in
     let modTime = getLastModificationTime(path).toUnix().int
     let (_, name, ext) = splitFile(path)
     let key = fmt"{name}{ext}:{modTime:x}:{tb}:{args}"
     return ($secureHash(key))[0..<16].toLowerAscii() & "faces"
   ```

3. **Binary I/O procs**:
   - `saveFaceCache(filename: string, data: seq[FaceCacheEntry])` - write binary format
   - `loadFaceCache(filename: string): seq[FaceCacheEntry]` - read binary format

4. **Public API**:
   - `readFaceCache*(path: string, tb: AVRational, args: string): Option[seq[FaceCacheEntry]]`
   - `writeFaceCache*(data: seq[FaceCacheEntry], path: string, tb: AVRational, args: string)`

**Binary format:**
- Header: version (uint16), frameCount (uint32)
- Per frame: frameIndex (uint32), timestamp (float32), faceCount (uint16)
- Per face: x, y, width, height (uint16), confidence (float32), angle (int16), stable (uint8)

**Cache location per CONTEXT decision:** `.honeyclip/` folder alongside video file, NOT getTempDir()
- Use `parentDir(path) / ".honeyclip"` for cache directory
- Create directory if not exists

**Cache eviction:** Limit to 20 face cache files per directory (faces are larger than motion data)
