  <action>
Extend src/analyze/faces.nim with adaptive sampling:

1. **SceneInfo type** for tracking scene state:
   ```nim
   type
     SceneInfo* = object
       score*: float  # 0.0-1.0 from scdet
       isSceneChange*: bool  # score > threshold
       timestamp*: float64
   ```

2. **AdaptiveSampler object**:
   ```nim
   type
     AdaptiveSampler* = object
       baseFps*: float  # Baseline sampling rate (default 1.0)
       maxFps*: float   # Maximum during spikes (default 5.0)
       currentFps: float
       sceneThreshold*: float  # Scene change threshold (default 0.4)
       cooldownDuration: float  # Seconds before returning to baseline (default 1.0)
       lastSpikeTime: float64
       lastFaceCount: int  # Track face state changes
   ```

3. **Sampler procs**:
   - `newAdaptiveSampler*(baseFps: float = 1.0, maxFps: float = 5.0, sceneThreshold: float = 0.4, cooldown: float = 1.0): AdaptiveSampler`
   - `updateSamplingRate*(sampler: var AdaptiveSampler, sceneScore: float, faceCount: int, currentTime: float64): float`
     - Returns maxFps if scene change OR face count changed
     - Returns baseFps if cooldown elapsed and no changes
     - Tracks lastSpikeTime and lastFaceCount for state

4. **Face detection pipeline iterator** (following videoPipeline pattern):
   ```nim
   iterator facesPipeline*(processor: VideoProcessor,
                          sampler: var AdaptiveSampler,
                          targetHeight: int = 480): tuple[frame: ptr AVFrame, sceneScore: float, timestamp: float64] =
     # Use FFmpeg filter: scale + format + scdet
     # scdet outputs scene scores in frame metadata
     # Yield frames at adaptive rate controlled by sampler
   ```

**FFmpeg filter setup:**
- Filter string: `fps={currentFps},scale=-1:{targetHeight},format=bgr24,scdet=t={sceneThreshold}:s=12`
- Extract scene score from frame side_data (AV_FRAME_DATA_DETECTION_BBOXES) or metadata
- Note: scdet score is in frame metadata as "lavfi.scd.score" or similar

**Key implementation details:**
- Scene change detection via scdet filter with threshold ~0.4 (per RESEARCH)
- Face state change: if abs(currentFaceCount - lastFaceCount) > 0, spike sampling
- Cooldown: maintain max FPS for cooldownDuration seconds after spike trigger
- Must NOT re-create filter graph on every FPS change - use select filter or post-filter frame skipping

**Practical approach for adaptive sampling:**
Since filter graph fps changes require rebuilding, use a different strategy:
1. Run pipeline at maxFps constantly
2. Use AdaptiveSampler to decide which frames to process (skip frames during baseline)
3. Always process frames during cooldown period
4. This avoids filter graph recreation while achieving adaptive behavior
