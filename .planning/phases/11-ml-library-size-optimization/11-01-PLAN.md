<task type="auto">
  <name>Task 1: Update OpenCV build configuration for size optimization</name>
  <files>honeyclip.nimble</files>
  <action>
Modify the `opencv` Package in honeyclip.nimble:

1. Change build type from Release to MinSizeRel:
   - Add: `-DCMAKE_BUILD_TYPE=MinSizeRel`
   - Remove any existing `-DCMAKE_BUILD_TYPE=Release` if present

2. Explicitly disable unwanted modules (BUILD_LIST alone is insufficient):
   - Add: `-DBUILD_opencv_calib3d=OFF`
   - Add: `-DBUILD_opencv_features2d=OFF`
   - Add: `-DBUILD_opencv_flann=OFF`
   - Add: `-DBUILD_opencv_dnn=OFF`
   - Add: `-DBUILD_opencv_gapi=OFF`
   - Add: `-DBUILD_opencv_highgui=OFF`
   - Add: `-DBUILD_opencv_ml=OFF`
   - Add: `-DBUILD_opencv_photo=OFF`
   - Add: `-DBUILD_opencv_video=OFF`
   - Add: `-DBUILD_opencv_stitching=OFF`
   - Add: `-DBUILD_opencv_videoio=OFF`

3. Disable unused 3rdparty dependencies (saves ~3MB):
   - Add: `-DWITH_CAROTENE=OFF` (ARM NEON HAL, redundant with Accelerate on macOS)
   - Add: `-DWITH_EIGEN=OFF` (matrix operations not needed)
   - Add: `-DWITH_ADE=OFF` (graph execution for gapi module)
   - Add: `-DWITH_FLATBUFFERS=OFF` (serialization not needed)
   - Add: `-DWITH_ITT=OFF` (Intel instrumentation not needed)

4. Keep existing optimizations:
   - Keep: `-DENABLE_LTO=ON`
   - Keep: all existing `-DWITH_*=OFF` flags
  </action>

<task type="auto">
  <name>Task 3: Update cmakeBuild to respect package-specified build type</name>
  <files>honeyclip.nimble</files>
  <action>
Modify the `cmakeBuild` proc to not override CMAKE_BUILD_TYPE when the package already specifies it:

1. Current behavior: cmakeBuild always adds `-DCMAKE_BUILD_TYPE=Release`
2. New behavior: Only add `-DCMAKE_BUILD_TYPE=Release` if not already in package.buildArguments

Find this block in cmakeBuild:
```nim
var cmakeArgs = @[
  &"-DCMAKE_INSTALL_PREFIX={buildPath}",
  "-DCMAKE_BUILD_TYPE=Release",
  ...
]
```

Change to:
```nim
var cmakeArgs = @[
  &"-DCMAKE_INSTALL_PREFIX={buildPath}",
  "-DBUILD_SHARED_LIBS=OFF",
  "-DBUILD_STATIC_LIBS=ON",
  "-DCMAKE_POLICY_VERSION_MINIMUM=3.5",
]

# Only add Release build type if package doesn't specify one
var hasBuildType = false
for arg in package.buildArguments:
  if arg.contains("CMAKE_BUILD_TYPE"):
    hasBuildType = true
    break
if not hasBuildType:
  cmakeArgs.add("-DCMAKE_BUILD_TYPE=Release")

cmakeArgs &= package.buildArguments
```

This ensures OpenCV and libfacedetection use MinSizeRel while other packages (whisper, svtav1) still use Release by default.
  </action>
  <verify>
Run: `grep -A 20 "proc cmakeBuild" honeyclip.nimble | grep -c "hasBuildType\|CMAKE_BUILD_TYPE"`
Expected: At least 2 matches showing the conditional logic
  </verify>
  <done>
cmakeBuild respects package-specified CMAKE_BUILD_TYPE instead of always overriding with Release.
  </done>
</task>
