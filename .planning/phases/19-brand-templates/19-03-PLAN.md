   - Create BatchTemplate with `brand.introOutro.introPath = "intro.mp4"`, `brand.introOutro.outroPath = "outro.mp4"`.

**Suite 2: "Watermark Filter"** (tests watermark.nim):

1. `test "buildWatermarkFilter bottom-right"`:
   - Call `buildWatermarkFilter("logo.png", wpBottomRight, 10, 10, 0.1, 1.0)`.
   - Check result contains `"overlay=W-w-10:H-h-10"`.
   - Check result contains `"[0:v][1:v]"` (full opacity, no colorchannelmixer).

4. `test "buildWatermarkFilter with opacity"`:
   - Call `buildWatermarkFilter("logo.png", wpBottomRight, 10, 10, 0.1, 0.7)`.
   - Check result contains `"colorchannelmixer=aa=0.7"`.
   - Check result contains `"[wm]"` (opacity pipeline label).

5. `test "buildWatermarkFilter empty path returns empty"`:
   - Call `buildWatermarkFilter("", wpBottomRight)`.
   - Check result == `""`.

6. `test "parseWatermarkPosition valid values"`:
   - Check `parseWatermarkPosition("top-left") == wpTopLeft`.
   - Check `parseWatermarkPosition("bottom-right") == wpBottomRight`.
   - Check `parseWatermarkPosition("center") == wpCenter`.

7. `test "parseWatermarkPosition unknown defaults to bottom-right"`:
   - Check `parseWatermarkPosition("invalid") == wpBottomRight`.
   - Check `parseWatermarkPosition("") == wpBottomRight`.
