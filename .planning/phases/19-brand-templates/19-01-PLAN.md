<task type="auto">
  <name>Task 2: Create watermark, concat, and caption style brand modules</name>
  <files>src/brand/watermark.nim, src/brand/concat.nim, src/brand/styles.nim</files>
  <action>
Create three new modules in `src/brand/` directory:

**src/brand/watermark.nim:**

1. Import `std/[strformat, strutils, os]` and `../render/captions` (for `escapeFilterPath`).

2. Define `WatermarkPosition` enum:
   - `wpTopLeft = "top-left"`
   - `wpTopRight = "top-right"`
   - `wpBottomLeft = "bottom-left"`
   - `wpBottomRight = "bottom-right"`
   - `wpCenter = "center"`

3. Create `proc parseWatermarkPosition*(s: string): WatermarkPosition`:
   - Maps string values to enum. Default to `wpBottomRight` for unknown values.

4. Create `proc buildWatermarkFilter*(imagePath: string, position: WatermarkPosition, offsetX: int = 10, offsetY: int = 10, scale: float = 0.1, opacity: float = 1.0): string`:
   - Returns empty string if imagePath is empty.
   - Build position expressions using FFmpeg overlay variables (W, H, w, h):
     - `wpTopLeft`: x=`{offsetX}`, y=`{offsetY}`
     - `wpTopRight`: x=`W-w-{offsetX}`, y=`{offsetY}`
     - `wpBottomLeft`: x=`{offsetX}`, y=`H-h-{offsetY}`
     - `wpBottomRight`: x=`W-w-{offsetX}`, y=`H-h-{offsetY}`
     - `wpCenter`: x=`(W-w)/2`, y=`(H-h)/2`
   - Build filter string. Two cases:
     - If opacity < 1.0: `[1:v]format=rgba,colorchannelmixer=aa={opacity}[wm];[0:v][wm]overlay={x}:{y}:format=auto`
     - If opacity == 1.0: `[0:v][1:v]overlay={x}:{y}:format=auto`
   - Note: The scale is applied separately by the caller using FFmpeg's `scale2ref` filter or `-vf scale` on the watermark input. This module only generates the overlay positioning filter.

5. Create `proc buildWatermarkScaleFilter*(scale: float): string`:
   - Returns `[1:v]scale2ref=w=oh*mdar:h=main_h*{scale}[wm][base]` to scale watermark relative to video height while preserving aspect ratio. This uses the `scale2ref` filter which references the main video dimensions.
   - If scale <= 0.0 or scale >= 1.0, return empty string (no scaling).

**src/brand/concat.nim:**

1. Import `std/[strformat, strutils, os, tempfiles, random]`.

2. Create `proc validateConcatFiles*(files: seq[string]): seq[string]`:
   - Returns list of error messages. Empty = valid.
   - Check each file exists, warn if not found.

3. Create `proc buildConcatList*(introPath, videoPath, outroPath: string, tempDir: string = ""): string`:
   - Builds an FFmpeg concat demuxer file list.
   - Each line: `file 'path'` (escape single quotes in paths by replacing `'` with `'\''`).
   - Order: intro (if non-empty and exists), video (always), outro (if non-empty and exists).
   - Write to temp file: `{tempDir or getTempDir()}/honeyclip_concat_{random}.txt`.
   - Return the temp file path.
   - Uses `randomize()` and `rand(100000..999999)` for unique filename (same pattern as `src/render/captions.nim:397`).

4. Create `proc cleanupConcatList*(path: string)`:
   - Remove the temp concat list file. Ignore errors if file doesn't exist.
   - Same pattern as `cleanupCaptionTemp` in captions.nim.

**src/brand/styles.nim:**

1. Import `../render/captions` (for `CaptionStyle`, `CaptionPosition`, `getPreset`).

2. Create type alias for clarity:
   ```nim
   type CaptionOverrides* = object
     preset*: string
     fontPath*: string
     fontSize*: int
     color*: string
     position*: string
   ```

3. Create `proc toCaptionStyle*(overrides: CaptionOverrides): CaptionStyle`:
   - Start with preset: if `overrides.preset != ""`, call `getPreset(overrides.preset)`, else `getPreset("traditional")`.
   - Apply overrides only when non-default:
     - `fontPath`: if != "", set `style.fontPath`
     - `fontSize`: if > 0, set `style.fontSize`
     - `color`: if != "", set `style.color`
     - `position`: map string to CaptionPosition:
       - "bottom" -> `cpBottomCenter`
       - "center" -> `cpCenter`
       - "top" -> `cpTopCenter`
       - else: keep preset default
   - Return the resulting CaptionStyle.

4. Create `proc parseCaptionPosition*(s: string): CaptionPosition`:
   - "bottom" -> `cpBottomCenter`
   - "center" -> `cpCenter`
   - "top" -> `cpTopCenter`
   - else -> `cpBottomCenter` (default)
