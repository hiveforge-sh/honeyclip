Create `src/reframe/easing.nim` with easing functions:

1. **EasingPreset enum** (re-export from types if needed):
   - `Slow` - cinematic, 1-2 second transitions
   - `Medium` - balanced, 0.5-1 second
   - `Fast` - social media, 0.2-0.5 second

2. **cubicBezier proc** (t: float, p0, p1, p2, p3: float) -> float:
   - Evaluate cubic bezier curve at parameter t (0 to 1)
   - Formula: u = 1-t; u^3*p0 + 3*u^2*t*p1 + 3*u*t^2*p2 + t^3*p3
   - Return value in range [0, 1]

3. **easingFunction proc** (t: float, preset: EasingPreset) -> float:
   - Apply easing to linear time parameter
   - Slow: cubic-bezier(0.0, 0.25, 0.25, 1.0) - gradual acceleration/deceleration
   - Medium: cubic-bezier(0.0, 0.42, 0.58, 1.0) - balanced ease-in-out
   - Fast: cubic-bezier(0.0, 0.55, 1.0, 1.0) - quick motion
   - Per RESEARCH code example

4. **getDuration proc** (preset: EasingPreset) -> float:
   - Return transition duration in seconds
   - Slow: 1.5 seconds
   - Medium: 0.75 seconds
   - Fast: 0.35 seconds
   - Per CONTEXT: slow = 1-2 sec, medium = 0.5-1 sec, fast = 0.2-0.5 sec

5. **lerp proc** (a, b: float, t: float) -> float:
   - Linear interpolation helper
   - Return a + (b - a) * t
