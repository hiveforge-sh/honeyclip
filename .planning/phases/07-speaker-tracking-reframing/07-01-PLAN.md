  <name>Task 2: Implement Kalman filter for motion prediction</name>
  <files>src/tracking/kalman.nim</files>
  <action>
Create `src/tracking/kalman.nim` with Kalman filter implementation:

1. **KalmanFilter object**:
   - `state: array[6, float]` - [x, y, width, height, vx, vy]
   - `covariance: array[6, array[6, float]]` - uncertainty matrix
   - `processNoise: float` - noise added during prediction (default 0.01)
   - `measurementNoise: float` - detection noise (default 0.1)

2. **newKalmanFilter proc**:
   - Initialize from first detection (x, y, w, h)
   - Set velocities to 0
   - Initialize covariance diagonal to 1.0

3. **predict proc** (KalmanFilter -> FaceRect):
   - Apply constant velocity model: x' = x + vx, y' = y + vy
   - Increase covariance by process noise
   - Return predicted bbox with confidence = 0.5 (predicted, not detected)
   - Per RESEARCH: Used during occlusion to maintain track position

4. **update proc** (KalmanFilter, detection: FaceRect):
   - Compute Kalman gain: K = P / (P + R)
   - Update state: state = state + K * (measurement - state)
   - Update velocity from position change
   - Reduce covariance: P = (1 - K) * P

5. **getBbox proc** (KalmanFilter -> tuple[x,y,w,h]):
   - Return current state as bounding box coordinates

Import types from `./types`. Follow simplified Kalman filter from RESEARCH.md code examples.

Note: Full matrix operations not required - simplified diagonal covariance is sufficient for face tracking per research.
