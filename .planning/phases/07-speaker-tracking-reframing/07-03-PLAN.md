  <files>src/tracking/assignment.nim</files>
  <action>
Create `src/tracking/assignment.nim` with optimal assignment:

1. **computeCostMatrix proc** (tracks: seq[Track], detections: seq[FaceDetection], embeddings: seq[seq[float32]]) -> seq[seq[float]]:
   - For each (track, detection) pair, compute cost
   - Cost = 0.7 * IoU_distance + 0.3 * appearance_distance
   - IoU_distance = 1.0 - IoU(track.bbox, detection)
   - Appearance_distance = 1.0 - cosineSimilarity(track.embedding, detection_embedding)
   - If IoU < 0.5: cost = 1e6 (infinite, per RESEARCH)
   - Return NxM cost matrix

2. **hungarianAssignment proc** (costMatrix: seq[seq[float]], threshold: float = 1e5) -> seq[tuple[trackIdx, detIdx: int]]:
   - Implement Hungarian/Munkres algorithm for optimal assignment
   - Standard O(n^3) implementation
   - Return list of (track_index, detection_index) matches
   - Exclude matches where cost > threshold

Hungarian algorithm steps (simplified):
1. Subtract row minimums
2. Subtract column minimums
3. Cover zeros with minimum lines
4. If lines < N: adjust matrix, repeat step 3
5. Find assignment from covered zeros

For small N (typically 1-5 faces in video), brute force with pruning also acceptable.

Import types from `./types`, iou from `../analyze/faces`, cosineSimilarity from `./embeddings`.

Create `src/tracking/tracker.nim` with multi-face tracker:

1. **FaceTracker object**:
   - `state: TrackingState` - current tracks
   - `embedder: FaceEmbedder` - for face embeddings (optional)
   - `maxAge: int` - frames before track deletion (default 90 = 3 sec at 30fps, per CONTEXT 3-second hold)
   - `minHits: int` - hits before track confirmed (default 3)
   - `iouThreshold: float` - IoU match threshold (default 0.5)
   - `embeddingThreshold: float` - cosine similarity threshold (default 0.7)

2. **newTracker proc** (modelPath: string = "", maxAge: int = 90, minHits: int = 3) -> FaceTracker:
   - Initialize TrackingState
   - Load embedder if modelPath provided (graceful skip if missing)
   - Set thresholds

3. **updateTracks proc** (tracker: var FaceTracker, detections: seq[FaceDetection], frame: ptr AVFrame) -> seq[Track]:
   - **Step 1: Predict** - For each track, kalman.predict() to get predicted bbox
   - **Step 2: Extract embeddings** - Get embedding for each detection (if embedder available)
   - **Step 3: Compute cost matrix** - Using predicted bboxes and embeddings
   - **Step 4: Hungarian assignment** - Find optimal matches
   - **Step 5: Update matched tracks**:
     - kalman.update(detection)
     - Update embedding as running average: 0.9 * old + 0.1 * new (per RESEARCH temporal smoothing)
     - Reset timeSinceUpdate = 0
     - Increment hitStreak
   - **Step 6: Handle unmatched detections** - Create new tracks with new IDs
   - **Step 7: Handle unmatched tracks** - Increment timeSinceUpdate, decrement hitStreak
   - **Step 8: Delete stale tracks** - Remove where timeSinceUpdate > maxAge
   - Return updated tracks

4. **getActiveTracks proc** (tracker: FaceTracker) -> seq[Track]:
   - Return tracks where hitStreak >= minHits (confirmed tracks only)
   - Per RESEARCH: newly detected faces may be false positives, require confirmation

5. **getActiveSpeaker proc** (tracker: FaceTracker, timestamp: float64, transcript: Transcript) -> Option[Track]:
   - Find speaker at timestamp from transcript diarization
   - Match to track using largest face heuristic (per RESEARCH Pattern 3)
   - Return track of active speaker, or none if no match

Import from types, kalman, embeddings, assignment. Handle missing embedder gracefully (IoU-only mode).
