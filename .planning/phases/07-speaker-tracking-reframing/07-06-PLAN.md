<task type="auto">
  <name>Task 1: Implement reframe CLI command</name>
  <files>src/cmds/reframe.nim</files>
  <action>
Create `src/cmds/reframe.nim` with speaker reframing command:

1. **Parse CLI arguments**:
   - `file` - input video file (required)
   - `--output, -o` - output file path (default: input_reframed.mp4)
   - `--aspect` - output aspect ratio: 9:16 (default), 16:9, 1:1
   - `--speed` - transition speed: slow (default), medium, fast
   - `--strategy` - speaker selection: active-speaker (default), largest-face
   - `--fallback` - fallback mode: center (default), motion
   - `--model` - whisper model for transcript (optional, for active-speaker strategy)
   - `--arcface` - path to ArcFace ONNX model (optional)
   - `--debug-speakers` - show colored boxes around tracked faces (per CONTEXT)
   - `--no-faces` - skip face tracking, use center crop only
   - `--help, -h` - show help

2. **Help text**:
```
usage: honeyclip reframe file [options]

Auto-reframe video to center active speaker

Arguments:
  file                    Input video file

Options:
  -o, --output PATH       Output file (default: input_reframed.mp4)
  --aspect RATIO          Output aspect: 9:16, 16:9, 1:1 (default: 9:16)
  --speed PRESET          Transition speed: slow, medium, fast (default: slow)
  --strategy MODE         Speaker selection: active-speaker, largest-face (default: active-speaker)
  --fallback MODE         Fallback: center, motion (default: center)
  --model NAME            Whisper model for transcript (needed for active-speaker)
  --arcface PATH          ArcFace ONNX model for re-identification
  --debug-speakers        Show colored boxes around tracked faces
  --no-faces              Skip face tracking, center crop only
  --help                  Show this help

Examples:
  honeyclip reframe podcast.mp4                    # Default 9:16 slow
  honeyclip reframe video.mp4 --aspect 1:1         # Square for Instagram
  honeyclip reframe video.mp4 --speed fast         # Quick TikTok-style transitions
```

3. **Main workflow**:
   - Open video, get dimensions and duration
   - If not --no-faces:
     - Run face detection (use faces() from Phase 4)
     - Initialize tracker with optional ArcFace model
     - Track faces across frames
     - If --strategy active-speaker and model provided:
       - Extract transcript
       - Correlate speaker segments with tracked faces
   - Build crop keyframes:
     - For each tracked frame, calculate crop region
     - Apply debounce (0.5 sec min hold per CONTEXT)
     - Use fallback when no faces detected
   - Initialize compositor with keyframes
   - Render reframed video
   - Show fallback percentage warning if >50%

4. **Progress reporting**:
   - "Detecting faces..." (with progress bar)
   - "Tracking speakers..." (if multiple faces)
   - "Rendering reframe..." (with progress bar)
   - Final: "Reframed to {output}" or warning about fallback

5. **Error handling**:
   - No video stream: error
   - No faces detected entire video: warning, proceed with center crop
   - Model file not found: warning, continue without embeddings

Follow existing CLI patterns from clips.nim. Import from tracking/, reframe/, analyze/.
