<task type="auto">
  <name>Task 1: Implement ArcFace embedding extraction</name>
  <files>src/tracking/embeddings.nim</files>
  <action>
Create `src/tracking/embeddings.nim` with face embedding functionality:

1. **FaceEmbedder object**:
   - `env: OrtEnv` - ONNX Runtime environment
   - `session: OrtSession` - loaded ArcFace model
   - `inputSize: int` - model input size (112 for standard ArcFace)
   - `embeddingDim: int` - output dimension (512 for ArcFace)

2. **initEmbedder proc** (modelPath: string) -> FaceEmbedder:
   - Check model file exists, raise helpful error if missing
   - Initialize OrtEnv
   - Load model with loadModel
   - Return configured embedder
   - Per RESEARCH: ArcFace model from OpenVINO model zoo (face-recognition-resnet100-arcface-onnx)

3. **preprocessFace proc** (imageData: ptr uint8, x, y, w, h, stride, imgW, imgH: int) -> seq[float32]:
   - Crop face region from image
   - Resize to 112x112 (ArcFace standard input)
   - Convert BGR to RGB
   - Normalize: (pixel - 127.5) / 128.0
   - Return flattened array [1, 3, 112, 112] = 37632 floats

4. **extractEmbedding proc** (embedder: FaceEmbedder, imageData: ptr uint8, x, y, w, h, stride, imgW, imgH: int) -> seq[float32]:
   - Call preprocessFace to get input tensor data
   - Create OrtValue tensor with shape [1, 3, 112, 112]
   - Run inference with session.run()
   - Extract 512-dim embedding from output
   - Normalize to unit length (L2 normalization)
   - Return seq[float32] of length 512

5. **cosineSimilarity proc** (a, b: seq[float32]) -> float:
   - Compute dot product of normalized vectors
   - Return similarity in range [-1, 1]
   - Per RESEARCH: similarity > 0.7 indicates same person

6. **releaseEmbedder proc** (embedder: var FaceEmbedder):
   - Clean up ONNX resources (handled by =destroy hooks)

Model input/output names for ArcFace ResNet100:
- Input: "data" shape [1, 3, 112, 112]
- Output: "fc1" shape [1, 512]

Note: If model not found, log warning and return empty embeddings (graceful degradation to IoU-only tracking).
