<task type="auto">
  <name>Task 1: Implement FFmpeg crop filter compositor</name>
  <files>src/reframe/compositor.nim</files>
  <action>
Create `src/reframe/compositor.nim` with video reframing:

1. **ReframeKeyframe object**:
   - `timestamp: float64` - when this keyframe applies
   - `crop: CropRegion` - crop region at this time
   - `trackId: int` - which track is being followed (-1 for fallback)

2. **Compositor object**:
   - `keyframes: seq[ReframeKeyframe]` - crop keyframes
   - `easing: EasingPreset` - transition easing
   - `targetAspect: AspectRatio` - output aspect ratio
   - `fallbackMode: string` - "center" or "motion"
   - `fallbackFrameCount: int` - frames using fallback
   - `totalFrameCount: int` - total frames processed

3. **newCompositor proc** (easing: EasingPreset = Slow, targetAspect: AspectRatio = Portrait) -> Compositor:
   - Initialize with default slow/cinematic easing
   - Default to 9:16 portrait output

4. **addKeyframe proc** (comp: var Compositor, timestamp: float64, crop: CropRegion, trackId: int):
   - Add keyframe to sequence
   - Track whether this is fallback (trackId == -1)
   - Increment appropriate frame counters

5. **generateCropFilter proc** (comp: Compositor, fps: float = 30.0) -> string:
   - Generate FFmpeg filter_complex string
   - Per RESEARCH code example: generate keyframes at high rate (60fps) for smooth motion
   - For each transition between keyframes:
     - Calculate intermediate crops using interpolateCrop
     - Generate crop= expressions with enable= for each segment
   - Return complete filter string

6. **getCropAtTime proc** (comp: Compositor, timestamp: float64) -> CropRegion:
   - Find keyframes surrounding timestamp
   - Interpolate between them using easing
   - Return interpolated crop region

7. **getFallbackPercentage proc** (comp: Compositor) -> float:
   - Calculate percentage of frames using fallback
   - Per CONTEXT: warn if >50%
   - Return fallbackFrameCount / totalFrameCount * 100

8. **renderReframe proc** (inputPath, outputPath: string, comp: Compositor, width, height: int):
   - Build FFmpeg command with crop filter
   - Use libx264 encoding (per Phase 6 pattern)
   - Apply filter chain: crop + scale to target resolution
   - Run FFmpeg process
   - Return success/failure

FFmpeg crop filter syntax: `crop=w:h:x:y:enable='between(t,start,end)'`
For dynamic cropping, use expression mode: `crop=w='{}':h='{}':x='{}':y='{}'`

Import from crop, easing, tracking types. Follow existing FFmpeg patterns from render/render.nim.
