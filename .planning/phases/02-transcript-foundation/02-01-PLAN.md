  <name>Task 1: Create transcript types module</name>
  <files>src/transcript/types.nim</files>
  <action>
Create `src/transcript/types.nim` with the following types:

```nim
type
  Word* = object
    text*: string
    startMs*: int64        # Milliseconds from start
    endMs*: int64
    confidence*: float     # 0.0-1.0, from whisper "p" field
    isNonSpeech*: bool     # true for [music], [noise]
    label*: string         # "music", "noise", empty for speech
    speaker*: int          # -1 = unassigned, 0+ = speaker index

  TranscriptSegment* = object
    words*: seq[Word]
    startMs*: int64
    endMs*: int64
    text*: string          # Combined text of all words
    speaker*: int

  Transcript* = object
    segments*: seq[TranscriptSegment]
    words*: seq[Word]      # Flat list of all words
    duration*: int64       # Total duration in ms
    language*: string      # Detected or specified language
```

Add helper procs:
- `newWord(text, startMs, endMs, confidence): Word`
- `newTranscript(): Transcript`
- `addWord(transcript, word)` - adds to both words seq and current segment
- `formatTimestamp(ms: int64, usePeriod: bool = false): string` - returns "HH:MM:SS,mmm" format (comma for SRT, period for VTT)
- `isLowConfidence(word: Word, threshold: float = 0.5): bool`

The timestamp formatter MUST use comma by default (SRT standard), with optional period for VTT.

<task type="auto">
  <name>Task 2: Implement word-level extraction from whisper JSON</name>
  <files>src/transcript/extract.nim</files>
  <action>
Create `src/transcript/extract.nim` that extracts word-level timestamps.

The existing whisper command uses FFmpeg's whisper filter with `format=json` and `max_len=1` for word splitting. The JSON output structure (from research) is:

```json
{
  "transcription": [
    {
      "timestamps": {"from": "00:00:00,000", "to": "00:00:02,500"},
      "offsets": {"from": 0, "to": 2500},
      "text": "word",
      "tokens": [{"text": "word", "p": 0.95, ...}]
    }
  ]
}
```

Implementation:
1. Create proc `extractTranscript*(inputPath: string, model: string, language: string = "", vadModel: string = ""): Transcript`
2. Use FFmpeg whisper filter (similar to existing whisper.nim) with:
   - `format=json`
   - `max_len=1` for word-level splitting
   - Output to temp file, parse JSON
3. Parse whisper JSON output:
   - Extract each segment's `offsets.from` and `offsets.to` as milliseconds
   - Get confidence from `tokens[0].p` if available, default 0.5
   - Detect non-speech markers: if text is "[music]", "[noise]", etc., set `isNonSpeech=true`
4. Build and return Transcript object

Import:
- std/[json, tempfiles, strutils]
- ../ffmpeg
- ../av
- ./types

Use the established FFmpeg filter pattern from whisper.nim but write to temp file instead of stdout, then parse JSON.
  </action>

`nim c --hints:off src/transcript/extract.nim` compiles without errors
  </verify>
  <done>
extractTranscript proc exists and can parse whisper JSON output with word-level timestamps
  </done>
</task>
