**Step 2: Create src/transcript/diarization.nim**

```nim
import std/[os, tables, strformat]
import nimpy
import ./types

type
  SpeakerSegment* = object
    startMs*: int64
    endMs*: int64
    speaker*: int

  DiarizationResult* = object
    segments*: seq[SpeakerSegment]
    numSpeakers*: int
```

Implement `diarizeAudio*(audioPath: string, maxSpeakers: int = 10): DiarizationResult`:

1. Check if HF_TOKEN environment variable is set (warn if not - model download may fail)
2. Import pyannote.audio via nimpy:
   ```nim
   let pyannote = pyImport("pyannote.audio")
   let pipeline = pyannote.Pipeline.from_pretrained(
     "pyannote/speaker-diarization-3.1",
     use_auth_token = getEnv("HF_TOKEN", "")
   )
   ```
3. Run diarization: `let diarization = pipeline(audioPath)`
4. Iterate results: `for (turn, _, speaker) in diarization.itertracks(yield_label = true)`
5. Convert to SpeakerSegment objects with ms timestamps
6. Return DiarizationResult with segments and speaker count

Handle errors:
- If pyannote import fails: raise with helpful message about pip install
- If model download fails: raise with HF_TOKEN setup instructions
- Wrap in try/except, return empty result with warning on failure

Implement `applySpeakersToTranscript*(transcript: var Transcript, diarization: DiarizationResult)`:

1. For each word in transcript.words:
   - Find overlapping speaker segment (word.startMs falls within segment)
   - Set word.speaker to segment.speaker
   - If no match found, set word.speaker = -1 (Unknown)
2. Update transcript.segments with majority speaker per segment

Implement `checkDiarizationAvailable*(): bool`:
- Try importing pyannote.audio
- Return true if successful, false otherwise
- Cache result to avoid repeated checks
