  <name>Task 1: Create caption grouping module</name>
  <files>src/transcript/grouping.nim</files>
  <action>
Create `src/transcript/grouping.nim` to group words into readable captions.

```nim
type
  Caption* = object
    words*: seq[Word]
    startMs*: int64
    endMs*: int64
    text*: string
    speaker*: int          # -1 if mixed/unknown
    speakerChanged*: bool  # True if speaker changed from previous caption
```

Implement `groupIntoCaptions*(transcript: Transcript, maxChars: int = 42, maxDuration: float = 5.0): seq[Caption]`:

1. Iterate through transcript.words
2. Build caption by adding words until:
   - Adding next word would exceed maxChars limit
   - Duration would exceed maxDuration seconds
   - Hit sentence boundary (word ends with . ? !)
   - Speaker changes (word.speaker != current speaker)
3. When breaking:
   - Prefer sentence boundaries if within 20% of limit
   - Never break before small words (a, the, to, of) - carry them to next line
   - Set speakerChanged=true if speaker differs from previous caption
4. Build text by joining word.text with spaces
5. Handle low-confidence marking: if word.isLowConfidence and threshold met, append "[?]" to word.text in caption

Helper proc `isSentenceEnd(word: Word): bool` - checks if text ends with . ? ! and isn't an abbreviation (Dr., Mr., Mrs., etc.)

Sentence boundary exceptions (not sentence end):
- Dr. Mr. Mrs. Ms. Prof. Jr. Sr. vs. etc. i.e. e.g.

<task type="auto">
  <name>Task 2: Create subtitle format exporters</name>
  <files>src/transcript/formats.nim</files>
  <action>
Create `src/transcript/formats.nim` with three export functions.

**SRT Format** (from research):
```
1
00:00:00,000 --> 00:00:02,500
This is the first subtitle.

2
00:00:02,500 --> 00:00:05,000
- Speaker 1: Second subtitle.
```

Implement `exportSRT*(captions: seq[Caption], outputPath: string, markLowConfidence: bool = true, confidenceThreshold: float = 0.5)`:
1. Write UTF-8 WITHOUT BOM (critical - BOM breaks players)
2. For each caption, write:
   - Index (1-based)
   - Timestamp line: `{start} --> {end}` using formatTimestamp with comma
   - Text line(s)
   - Blank line
3. If caption.speakerChanged, prefix text with "- Speaker {n}: " (only on change)
4. If markLowConfidence, words below threshold get "[?]" suffix in text

**VTT Format** (from research):
```
WEBVTT

00:00:00.000 --> 00:00:02.500
<v Speaker1>This is the first subtitle.

00:00:02.500 --> 00:00:05.000
<v Speaker2>Second subtitle.
```

Implement `exportVTT*(captions: seq[Caption], outputPath: string, speakerColors: bool = false, markLowConfidence: bool = true, confidenceThreshold: float = 0.5)`:
1. Write "WEBVTT\n\n" header (UTF-8 without BOM)
2. Timestamps use period, not comma
3. If speakerChanged, add `<v Speaker{n}>` voice span
4. If speakerColors, add styling (optional - Claude's discretion on color palette)

**JSON Format**:
```json
{
  "language": "en",
  "duration_ms": 12500,
  "words": [...],
  "captions": [...]
}
```

Implement `exportJSON*(transcript: Transcript, captions: seq[Caption], outputPath: string, compact: bool = false)`:
1. Include full word list with timestamps, confidence, speaker
2. Include grouped captions
3. If compact, use `$` instead of `pretty()`
4. Write UTF-8 without BOM

All exporters: if outputPath == "-", write to stdout. Otherwise write to file.
