**CLI Options (from CONTEXT.md decisions):**
```
usage: honeyclip transcript file model [options]

Options:
  -o, --output DIR        Output directory (default: same as input)
  --format FORMAT         Output format for --stdout (srt, vtt, json)
  --max-chars NUM         Max characters per caption line (default: 42)
  --single-speaker        Skip speaker diarization
  --speaker-map FILE      JSON file mapping speaker IDs to names
  --speaker-colors        Enable VTT speaker colors (default: off)
  --language LANG         Override language detection
  --vad-model PATH        VAD model for whisper
  --confidence NUM        Confidence threshold for [?] markers (default: 0.5)
  --compact               Minified JSON output
  --dry-run               Preview transcript without writing files
  --stdout                Output to terminal (requires --format)
  --no-backup             Don't create .bak files when overwriting
  --help                  Show this help
```

**Implementation:**

```nim
proc main*(cArgs: seq[string]) =
  # 1. Parse arguments (follow whisper.nim pattern)
  # 2. Validate: file exists, model specified

  # 3. Check if output files exist, backup if needed (unless --no-backup)

  # 4. Extract transcript with word timestamps
  let transcript = extractTranscript(inputPath, model, language, vadModel)

  # 5. Run diarization unless --single-speaker
  if not singleSpeaker and checkDiarizationAvailable():
    let diarization = diarizeAudio(extractedAudioPath, maxSpeakers=10)
    applySpeakersToTranscript(transcript, diarization)
  elif not singleSpeaker:
    # Warn: pyannote not available, skipping diarization

  # 6. Group into captions
  let captions = groupIntoCaptions(transcript, maxChars)

  # 7. Load speaker map if provided
  let speakerMap = if speakerMapPath != "": loadSpeakerMap(speakerMapPath) else: initTable[int, string]()

  # 8. Export based on mode
  if dryRun:
    # Print summary: word count, speaker count, duration
    echo "Transcript preview:"
    echo &"  Duration: {transcript.duration / 1000:.1f}s"
    echo &"  Words: {transcript.words.len}"
    echo &"  Speakers: {countSpeakers(transcript)}"
    echo &"  Captions: {captions.len}"
  elif stdout:
    case format:
    of "srt": exportSRT(captions, "-", speakerMap=speakerMap)
    of "vtt": exportVTT(captions, "-", speakerColors, speakerMap=speakerMap)
    of "json": exportJSON(transcript, captions, "-", compact, speakerMap=speakerMap)
  else:
    # Default: output all three formats
    let basePath = outputDir / splitFile(inputPath).name
    exportSRT(captions, basePath & ".srt", speakerMap=speakerMap)
    exportVTT(captions, basePath & ".vtt", speakerColors, speakerMap=speakerMap)
    exportJSON(transcript, captions, basePath & ".json", compact, speakerMap=speakerMap)
    echo &"Created: {basePath}.srt, .vtt, .json"
```

**Backup logic:**
- Before writing, check if output exists
- If exists and not --no-backup: rename to .bak
- If .bak exists: overwrite .bak (only keep one backup)

**Error handling:**
- If model file doesn't exist: prompt "Model not found at {path}. Download from https://huggingface.co/ggerganov/whisper.cpp? [y/n]"
- If input has no audio: error "No audio stream found"
- If diarization fails: warn and continue without speaker labels
