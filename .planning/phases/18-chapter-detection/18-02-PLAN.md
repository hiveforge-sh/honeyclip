**CLI arguments** (follow clips.nim pattern for arg parsing):
- Positional: `file` (required), `model` (whisper model, auto-detected if not provided)
- `--mode MODE`: "scene", "engagement", "combined" (default: "combined")
- `--export FORMAT`: "mp4", "fcpxml", "edl", "json" (default: print list to terminal)
- `-o, --output PATH`: Output file path (default: auto-generated from input)
- `--threshold N`: Scene detection threshold (default: 0.4, passed to extractSceneChanges)
- `--min-spacing SECS`: Minimum seconds between chapters (default: 30)
- `--min-score N`: Minimum engagement score for peaks (default: 60)
- `--max-chapters N`: Maximum number of chapters (default: 10)
- `--no-faces`: Skip face detection
- `--hooks PATH`: Custom hook patterns
- `--no-transcript`: Skip transcript (scene-only mode)
- `--debug`: Debug mode
- `-q, --quiet`: Suppress progress output
- `--help, -h`: Show help text

**Help text:**
```
usage: honeyclip chapters file [model] [options]

Auto-generate chapters from scene changes and engagement peaks

Arguments:
  file                    Input video file
  model                   Whisper model (auto-detected from ~/.cache/whisper/)

Options:
  --mode MODE             Chapter detection mode: scene, engagement, combined
                          (default: combined)
  --export FORMAT         Export format: mp4, fcpxml, edl, json
                          (default: print to terminal)
  -o, --output PATH       Output file path
  --threshold N           Scene detection threshold 0.0-1.0 (default: 0.4)
  --min-spacing SECS      Minimum seconds between chapters (default: 30)
  --min-score N           Minimum engagement score for peaks (default: 60)
  --max-chapters N        Maximum number of chapters (default: 10)
  --no-faces              Skip face detection (faster)
  --no-transcript         Skip transcript (scene-only mode)
  --hooks PATH            Custom hook patterns JSON file
  -q, --quiet             Suppress progress output
  --debug                 Show debug information
  --help                  Show this help

Modes:
  scene       - Chapters at visual scene changes
  engagement  - Chapters at high-engagement peaks
  combined    - Both sources merged (default)

Examples:
  honeyclip chapters video.mp4                           # List chapters
  honeyclip chapters video.mp4 --mode scene              # Scene-only
  honeyclip chapters video.mp4 --export mp4              # Embed in MP4
  honeyclip chapters video.mp4 --export fcpxml -o ch.xml # FCPXML markers
```

**Main proc pipeline** (follow clips.nim Steps 1-5 pattern):

1. Parse args (same pattern as clips.nim)
2. If `mode` requires engagement (mode != "scene"), validate model exists. If mode is "scene" and no model specified, auto-set `--no-transcript`.
3. Extract transcript (unless --no-transcript)
4. Open container, get timebase
5. Load hooks (if engagement mode)
6. Analyze engagement (unless mode == "scene" — in scene-only mode, skip engagement, create a dummy empty timeline with just the duration from the container)
7. Detect scene changes (unless mode == "engagement"): call `extractSceneChanges(inputPath, threshold)` from clips.nim
8. Build ChapterParams from CLI args
9. Call `detectEngagementPeaks` (if mode != "scene")
10. Call `generateChapters` with scene times, peaks, timeline, params
11. Print chapter list to terminal (always, unless --quiet)
12. If --export specified, export:
    - "mp4": Convert chapters to ChapterMarker via `chaptersToMetadata`, write ffmetadata file via `writeFFMetadataFile`, then apply to video via FFmpeg `-i input -i metadata -map_metadata 1 -codec copy output`. Use `execProcess` to run FFmpeg. Default output path: `{input}_chapters.{ext}`.
    - "fcpxml": Convert to Markers via `chaptersToMarkers`, call `writeMarkersFCPXML`. Default output: `{input}_chapters.fcpxml`.
    - "edl": Convert to Markers via `chaptersToMarkers`, call `exportMarkersEDL`. Default output: `{input}_chapters.edl`.
    - "json": Write chapters as JSON array (use `std/json`, create `%*` object per chapter with startMs, endMs, title, source, score). Default output: `{input}_chapters.json`.

**Chapter list printing** (similar to clips.nim `printClipList`):
```nim
proc printChapterList*(chapters: seq[Chapter], duration: int64) =
  echo ""
  echo &"Detected Chapters ({chapters.len} total)"
  echo "=========================="
  echo ""
  for i, ch in chapters:
    let startTime = formatTimestamp(ch.startMs)  # Reuse from clips cmd or define locally
    let endTime = formatTimestamp(ch.endMs)
    let durSec = (ch.endMs - ch.startMs) div 1000
    let sourceStr = if ch.source == csEngagement: "engagement" else: "scene"
    let scoreStr = if ch.score > 0: &" (score: {ch.score:.0f})" else: ""
    echo &"  {i+1}. {startTime}-{endTime} ({durSec}s) [{sourceStr}]{scoreStr}"
    echo &"      {ch.title}"
  echo ""
```

Define `formatTimestamp` locally (same pattern as clips.nim: `[M:SS]` format) to avoid import issues.
