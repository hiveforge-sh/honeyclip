**Types:**
```nim
type
  ChapterSource* = enum
    csScene         ## From scene change detection
    csEngagement    ## From engagement peak detection

  Chapter* = object
    startMs*: int64
    endMs*: int64
    title*: string
    source*: ChapterSource
    score*: float32    # Engagement score (0 if scene-only)

  ChapterParams* = object
    mode*: string                # "scene", "engagement", "combined" (default "combined")
    sceneThreshold*: float       # Scene detection threshold for FFmpeg scdet (default 0.4, passed through to extractSceneChanges)
    minSpacingMs*: int64         # Minimum ms between chapters (default 30000)
    minScore*: float32           # Minimum engagement score for peaks (default 60.0)
    maxChapters*: int            # Maximum number of chapters (default 10)
    dedupeWindowMs*: int64       # Window for merging nearby scene+engagement markers (default 5000)
```

**Default params:**
```nim
proc defaultChapterParams*(): ChapterParams =
  result.mode = "combined"
  result.sceneThreshold = 0.4
  result.minSpacingMs = 30000     # 30 seconds
  result.minScore = 60.0f
  result.maxChapters = 10
  result.dedupeWindowMs = 5000    # 5 seconds
```

**Peak detection:**
```nim
proc detectEngagementPeaks*(timeline: EngagementTimeline,
                             minSpacingMs: int64 = 30000,
                             minScore: float32 = 60.0,
                             maxPeaks: int = 10): seq[int64] =
```

Algorithm (from RESEARCH.md Pattern 2):
1. Find local maxima: for each segment i (1..len-2), if `segments[i].score >= minScore` AND `segments[i].score > segments[i-1].score` AND `segments[i].score > segments[i+1].score`, add as candidate with (startMs, score).
2. Sort candidates by score descending.
3. Greedy selection with minimum spacing: iterate candidates, skip if any selected peak is within `minSpacingMs`.
4. Cap at `maxPeaks`.
5. Sort selected timestamps chronologically and return.

This proc must be exported (add `*`) for unit testing.

**Chapter generation:**
```nim
proc generateChapters*(sceneTimes: seq[float64],
                        engagementPeaks: seq[int64],
                        timeline: EngagementTimeline,
                        params: ChapterParams): seq[Chapter] =
```

Implementation by mode (from RESEARCH.md Pattern 3):

**Mode "scene":**
- Convert scene timestamps from seconds (float64) to milliseconds (int64).
- Filter scenes that are within `minSpacingMs` of each other (keep first).
- For each scene time, create Chapter with source=csScene, title="Scene N" (1-indexed).
- Set endMs to next chapter's startMs - 1, or timeline.duration for last chapter.
- Cap at maxChapters (keep evenly distributed if too many: take every Nth).

**Mode "engagement":**
- Use engagement peak timestamps directly.
- For each peak, find engagement score from timeline segments (segment where peak falls within startMs..endMs).
- Create Chapter with source=csEngagement, title using labelForScore (from markers module): e.g., "Peak #1 - High engagement".
- Set endMs to next chapter's startMs - 1, or timeline.duration for last chapter.

**Mode "combined":**
- Collect all scene times (as ms) and engagement peaks into a unified list with source tags.
- Sort by timestamp.
- Deduplicate: if two markers are within `dedupeWindowMs`, keep the engagement one (higher information value). If both same source, keep first.
- Apply minSpacing filter across combined list.
- Cap at maxChapters.
- Generate titles: engagement chapters get "Peak #N - {label}", scene chapters get "Scene N".
- Set endMs to next startMs - 1 or timeline.duration for last.

**CRITICAL:** Per RESEARCH.md Pitfall 4, endMs must be startMs of next chapter minus 1 (not equal to next startMs). Last chapter endMs = timeline.duration.

**Export conversions:**

```nim
proc chaptersToMetadata*(chapters: seq[Chapter]): seq[ChapterMarker] =
```
Convert each Chapter to ChapterMarker (from metadata/types): startMs, endMs, title. This is used by the existing `generateFFMetadata` proc in metadata/apply.nim.

```nim
proc chaptersToMarkers*(chapters: seq[Chapter]): seq[Marker] =
```
Convert each Chapter to Marker (from exports/markers):

- durationMs: chapter.endMs - chapter.startMs
- name: chapter.title
- comment: "Score: {score}/100" for engagement, "Scene boundary" for scene
- color: getMarkerColor(markerType)

Both procs must be exported for CLI use.
