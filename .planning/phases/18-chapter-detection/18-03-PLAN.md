<feature>
  <name>Chapter Detection Unit Tests</name>
  <files>tests/unit.nim, src/analyze/chapters.nim</files>
  <behavior>
  Tests for the chapter detection module covering:

  **1. detectEngagementPeaks:**
  - Empty timeline (0 segments) -> returns empty seq
  - Single segment -> returns empty seq (no neighbors to compare)
  - Two segments -> returns empty seq (need at least 3 for local maxima)
  - Clear peak in middle: [20, 80, 20] -> returns [middle segment startMs]
  - Multiple peaks with spacing: scores [20, 80, 20, 90, 30] with sufficient spacing -> returns both peaks sorted chronologically
  - Peaks too close together: two peaks within minSpacingMs -> returns only the higher-scoring one
  - All scores below minScore -> returns empty seq
  - maxPeaks limit: 5 peaks detected but maxPeaks=2 -> returns top 2 by score
  - Plateau: [50, 80, 80, 50] -> neither 80 is a local max (equal neighbor), returns empty

  **2. generateChapters (scene mode):**
  - Scene times [0.0, 30.0, 60.0] with duration 90000ms -> 3 chapters with correct startMs/endMs
  - endMs of each chapter = next startMs - 1, last endMs = duration
  - Chapters titled "Scene 1", "Scene 2", etc.
  - All chapters have source=csScene and score=0.0
  - Empty scene times -> returns empty seq
  - Scene times filtered by minSpacing

  **3. generateChapters (engagement mode):**
  - Engagement peaks [15000, 45000, 75000] -> 3 chapters with source=csEngagement
  - Score looked up from timeline segments
  - Titles include score label via labelForScore

  **4. generateChapters (combined mode):**
  - Scene at 30000ms and engagement peak at 32000ms (within 5000ms dedupe window) -> merged to 1 chapter (engagement kept)
  - Scene at 30000ms and engagement peak at 60000ms (outside window) -> 2 separate chapters
  - Combined result sorted chronologically
  - maxChapters limit enforced

  **5. chaptersToMetadata:**
  - Converts Chapter seq to ChapterMarker seq with matching startMs, endMs, title
  - Empty input -> empty output

  **6. chaptersToMarkers:**
  - csEngagement chapters -> Marker with markerType=mtEngagementPeak
  - csScene chapters -> Marker with markerType=mtSceneBoundary
  - Marker colors match getMarkerColor(markerType)
  - Empty input -> empty output

  **Helper:** Create test timelines using `newEngagementSegment` with set scores, following the pattern from Phase 17 virality tests (use `check` and `checkApprox` for float comparisons).
  </behavior>
  <implementation>
  Add import `import ../src/analyze/chapters` at top of unit.nim (alongside existing analyze imports).

  Create helper proc `makeTimeline(scores: seq[float32], segDurationMs: int64 = 10000): EngagementTimeline` that creates a timeline with segments at regular intervals matching the given scores.
  Write test cases using `check` assertions. Use `checkApprox` helper (already defined in unit.nim from Phase 17) for float comparisons where needed.
  Target: ~15-20 tests covering all the behaviors listed above.
  </implementation>
</feature>
