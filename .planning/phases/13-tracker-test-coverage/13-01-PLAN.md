**Test cases to add:**

1. `test "iou-perfect-overlap"`:
   - Two identical FaceRects at same position/size
   - Verify iou() returns 1.0

2. `test "iou-no-overlap"`:
   - Two FaceRects far apart (no intersection)
   - Verify iou() returns 0.0

3. `test "iou-partial-overlap"`:
   - FaceRect A: (0, 0, 100, 100), FaceRect B: (50, 50, 100, 100)
   - Intersection: 50x50 = 2500
   - Union: 10000 + 10000 - 2500 = 17500
   - IoU = 2500/17500 ≈ 0.1428
   - Verify with checkApprox(iou(a, b), 0.1428, epsilon=0.001)

4. `test "iou-edge-touching"`:
   - FaceRect A: (0, 0, 50, 50), FaceRect B: (50, 0, 50, 50)
   - Boxes touch at edge but don't overlap
   - Verify iou() returns 0.0

5. `test "iou-one-inside-other"`:
   - Large box: (0, 0, 200, 200), Small box: (50, 50, 50, 50)
   - Intersection = small box area = 2500
   - Union = 40000 + 2500 - 2500 = 40000
   - IoU = 2500/40000 = 0.0625
   - Verify with checkApprox

6. `test "costMatrix-empty-tracks"`:
   - Empty tracks seq, non-empty detections
   - Verify returns empty matrix (len == 0)

7. `test "costMatrix-empty-detections"`:
   - Non-empty tracks, empty detections
   - Verify returns matrix with empty rows

8. `test "costMatrix-sets-infinite-for-low-iou"`:
   - Track at (0, 0, 50, 50), detection at (500, 500, 50, 50)
   - IoU < 0.5 threshold
   - Verify costMatrix[0][0] >= 1e5 (infinite cost)

9. `test "costMatrix-calculates-valid-cost"`:
   - Track at (100, 100, 50, 50), detection at (105, 102, 50, 50)
   - IoU > 0.5 (high overlap)
   - Verify costMatrix[0][0] < 1e5 and > 0

10. `test "hungarian-empty-matrix"`:
    - Empty cost matrix
    - Verify hungarianAssignment returns empty seq

11. `test "hungarian-single-assignment"`:
    - 1x1 cost matrix with cost 0.5
    - Verify returns @[(trackIdx: 0, detIdx: 0)]

12. `test "hungarian-rejects-high-cost"`:
    - 1x1 cost matrix with cost > 1e5 (threshold)

13. `test "hungarian-two-tracks-two-detections"`:
