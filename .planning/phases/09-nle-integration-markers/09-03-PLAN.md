  <name>Task 1: Add marker element generation to FCPXML</name>
  <files>src/exports/fcp11.nim</files>
  <action>
Extend `src/exports/fcp11.nim` with FCPXML marker support:

1. Import the markers module at top:
   ```nim
   import markers
   ```

2. Add `addMarkerFCPXML*` proc:
   ```nim
   proc addMarkerFCPXML*(parent: XmlNode, marker: Marker, tb: AVRational) =
     ## Add a single marker element to FCPXML
     ##
     ## FCPXML marker format (simpler than FCP7):
     ## <marker start="10s" duration="1s" value="Peak #1" note="Score: 85/100"/>
     ##
     ## FCPXML uses rational time (e.g., "1001/30000s") or simple seconds
     ##
     ## Args:
     ##   parent: The clip or spine element to add marker to
     ##   marker: Marker data
     ##   tb: Timebase for timing calculation
   ```

   Implementation:
   - Convert timestampMs to FCPXML rational time format using existing fraction() pattern
   - Build marker element with attributes: start, duration, value (name), note (comment)
   - Note: FCPXML markers don't support custom colors in the XML, color is set by marker type in FCP

3. Add `addMarkersFCPXML*` proc:
   ```nim
   proc addMarkersFCPXML*(parent: XmlNode, markers: seq[Marker], tb: AVRational) =
     ## Add multiple markers to a parent element (clip, gap, or spine)
     for marker in markers:
       addMarkerFCPXML(parent, marker, tb)
   ```

4. Add standalone export function:
   ```nim
   proc writeMarkersFCPXML*(videoPath: string, markers: seq[Marker], outputPath: string) =
     ## Write FCPXML file with markers on video clip
     ## Creates: fcpxml > resources + library > event > project > sequence > spine > asset-clip with markers
   ```

   Follow the pattern from `writeCaptionOnlyFCPXML`:
   - Load MediaInfo for video dimensions and timebase
   - Create resources (format + asset)
   - Create library/event/project/sequence/spine structure
   - Create asset-clip for video
   - Add markers to the asset-clip element
  </action>
