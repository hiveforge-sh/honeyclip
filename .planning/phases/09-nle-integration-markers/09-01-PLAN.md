<task type="auto">
  <name>Task 1: Create marker types module</name>
  <files>src/exports/markers.nim</files>
  <action>
Create `src/exports/markers.nim` with:

1. MarkerType enum:
   - `mtEngagementPeak` - High engagement moment
   - `mtSceneBoundary` - Visual scene change
   - `mtSpeakerChange` - New speaker begins

2. MarkerColor constants (hex strings):
   - Green (#00FF00) for engagement peaks
   - Blue (#0066FF) for scene boundaries
   - Yellow (#FFCC00) for speaker changes

3. Marker object with fields:
   - `markerType: MarkerType`
   - `timestampMs: int64` - Position in milliseconds
   - `durationMs: int64` - Marker duration (default 1000ms)
   - `name: string` - Short display name (e.g., "Engagement Peak #1")
   - `comment: string` - Detailed description (e.g., "Score: 85/100 (#2) - High engagement")
   - `color: string` - Hex color for display

4. Factory functions:
   - `createEngagementMarker(timestampMs, score, rank: int): Marker`
     - Name: "Peak #{rank}"
     - Comment: "Score: {score}/100 (#{rank}) - {label}" where label is High/Medium/Low based on score
   - `createSceneMarker(timestampMs: int64): Marker`
     - Name: "Scene"
     - Comment: "Scene boundary at {timecode}"
   - `createSpeakerMarker(timestampMs: int64, speakerId: int, speakerName: string = ""): Marker`
     - Name: "Speaker: {name}" or "Speaker {id}" if no name
     - Comment: "Speaker change to {name/id}"

5. Utility functions:
   - `getMarkerColor(mt: MarkerType): string` - Returns hex color for type
   - `msToTimecode(ms: int64, fps: float = 30.0): string` - Format as HH:MM:SS:FF
   - `labelForScore(score: float32): string` - Returns "High"/"Medium"/"Low"
  </action>
