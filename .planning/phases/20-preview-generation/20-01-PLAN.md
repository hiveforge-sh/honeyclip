  <action>
Create `src/render/proxy.nim` — the core proxy generation module. Follow the patterns established in `src/render/previews.nim` (FFmpeg path finding, execCmd usage).

**Types:**
- `EncoderConfig` object: codec (string), preset (string), tune (string, optional), pixelFormat (string), bitrateMode (string: "crf" or "vbr"), bitrateValue (string)
- `ProxyResult` object: outputPath (string), success (bool), speedFactor (float), error (string)

**Procs to implement:**

1. `selectProxyEncoder*(gpuRuntime: GpuRuntime): EncoderConfig` — Select optimal encoder based on GPU detection from Phase 15:
   - CUDA: codec="h264_nvenc", preset="p1", pixelFormat="yuv420p", bitrateMode="vbr", bitrateValue="2M"
   - CoreML: codec="h264_videotoolbox", preset="veryfast", pixelFormat="nv12", bitrateMode="vbr", bitrateValue="2M"
   - CPU: codec="libx264", preset="ultrafast", tune="fastdecode", pixelFormat="yuv420p", bitrateMode="crf", bitrateValue="28"

2. `buildProxyPath*(inputPath: string): string` — Generate output path: same directory, `{name}_proxy.mp4` suffix. Example: `/videos/talk.mp4` → `/videos/talk_proxy.mp4`

3. `buildFFmpegArgs*(inputPath, outputPath: string, encoder: EncoderConfig): seq[string]` — Build complete FFmpeg argument list:
   - `-y` (overwrite)
   - `-i inputPath`
   - `-vf "scale=1280:720:flags=fast_bilinear"` (fast downscale to 720p)
   - Encoder-specific flags based on EncoderConfig
   - For CRF mode: `-crf {value}`
   - For VBR mode: `-b:v {value}`, `-rc vbr` (NVENC only), `-maxrate 3M`, `-bufsize 4M`
   - Audio: `-c:a aac -b:a 128k -ar 48000`
   - `-movflags +faststart`
   - Output path

4. `parseProgress*(line: string, durationSec: float): tuple[progress: float, speed: float]` — Parse FFmpeg stderr line for progress. Look for `time=HH:MM:SS.MS` and `speed=Nx`. Return progress percentage (0-100) and speed factor. Return (-1, -1) if line doesn't contain progress info.

5. `generateProxy*(inputPath: string, outputPath: string = "", quiet: bool = false): ProxyResult` — Main entry point:
   - Call `detectGpu()` from gpu_runtime module
   - Call `logBackend()` (unless quiet)
   - Select encoder via `selectProxyEncoder()`
   - Determine output path (use outputPath if provided, else buildProxyPath)
   - Find FFmpeg via `findFFmpegPath()` from previews module
   - Build args via `buildFFmpegArgs()`
   - Execute FFmpeg via `startProcess` (not execCmd — need stderr for progress)
   - Parse stderr lines for progress, call `conwrite` for live progress updates (unless quiet)
   - Track wall clock time to compute actual speed factor
   - Return ProxyResult with success status, output path, and speed factor
   - On failure, return ProxyResult with success=false and error message

**Imports:** `std/[strformat, strutils, os, osproc, times]`, `../ml/gpu_runtime`, `../render/previews` (for findFFmpegPath), `../log` (for conwrite, error)

**Important:** Use `startProcess` with `poStdErrToStdOut` to capture FFmpeg progress output. Parse each line looking for `time=` pattern. Use `conwrite` (existing in log module) for in-place progress updates.

**Windows note:** On Windows, gpu_runtime returns CPU backend, which is correct — the ultrafast x264 path will be used.

**Arguments to support:**
- `file` (positional, required) — Input video file
- `-o, --output PATH` — Output file path (default: auto-generated `_proxy.mp4`)
- `-q, --quiet` — Suppress progress output
- `--help, -h` — Print help and quit

**Help text:**
```
usage: honeyclip preview file [options]

Generate 720p proxy preview for fast review

Arguments:
  file                    Input video file

Options:
  -o, --output PATH       Output file path (default: {input}_proxy.mp4)
  -q, --quiet             Suppress progress output
  --help                  Show this help

Examples:
  honeyclip preview video.mp4                    # Generate proxy
  honeyclip preview video.mp4 -o proxy.mp4       # Custom output path
```

**Main logic after parsing:**
1. Validate inputPath is not empty, file exists
2. Import and call `generateProxy(inputPath, outputPath, quiet)` from render/proxy
3. Check result.success — if false, call `error result.error`
4. If not quiet, print summary: "Proxy created: {outputPath} ({speedFactor:.1f}x realtime)"

**Imports:** `std/[strformat, strutils, os]`, `../log`, `../util/fun`, `../render/proxy`
