2. Add these virality calculation procs before `detectClips()`:

   **calculateHookScore(firstSegment: EngagementSegment): float32**
   - Base score = firstSegment.score
   - If firstSegment.hasHook, add 15.0 bonus (capped at 100.0)

   **calculateFlowScore(segments: seq[EngagementSegment]): float32**
   - Calculate average score across all segments
   - Calculate standard deviation of scores
   - Penalty = min(stdDev * 0.5, 30.0) (cap at 30 points)
   - Result = max(0.0, avgScore - penalty)
   - Return 0.0 for empty segments

   **calculateValueScore(segments: seq[EngagementSegment], maxFaceCount: int): float32**
   - Calculate average score across all segments
   - Face boost = min(maxFaceCount * 3.0, 15.0) (cap at 15 points total)
   - Result = min(100.0, avgScore + faceBoost)
   - Return 0.0 for empty segments

   **calculateTrendScore(segments: seq[EngagementSegment]): float32**
   - Collect unique hook pattern names from all segments' hookMatches into a HashSet[string]
   - If no patterns found, return 50.0 (neutral)
   - Result = min(100.0, uniquePatterns.len * 33.33) (1 pattern=33, 2=67, 3+=100)

   **calculateViralityComponents(segments: seq[EngagementSegment], maxFaceCount: int): ViralityComponents**
   - Calls the four component calculators above
   - Returns ViralityComponents object

   **combineViralityScore(components: ViralityComponents): float32**
   - Weighted average: hook * 0.35 + flow * 0.30 + value * 0.25 + trend * 0.10
   - These weights come from research: Hook 35%, Flow 30%, Value 25%, Trend 10%
