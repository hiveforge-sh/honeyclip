  <behavior>
  Test cases with expected inputs/outputs:

  **calculateHookScore:**
  - Segment with score=70, hasHook=false -> 70.0
  - Segment with score=70, hasHook=true -> 85.0 (70 + 15 boost)
  - Segment with score=90, hasHook=true -> 100.0 (capped at 100)

  **calculateFlowScore:**
  - Segments [80, 80, 80] (no variance) -> ~80.0
  - Segments [50, 100, 50, 100] (high variance) -> avg 75 minus penalty
  - Empty segments -> 0.0
  - Single segment [60] -> 60.0 (no variance)

  **calculateValueScore:**
  - Segments avg=70, faceCount=0 -> 70.0
  - Segments avg=70, faceCount=2 -> 76.0 (70 + 2*3)
  - Segments avg=90, faceCount=10 -> 100.0 (capped: 90 + min(30, 15) = 105 -> 100)

  **calculateTrendScore:**
  - No hook patterns -> 50.0 (neutral)
  - 1 unique pattern -> ~33.3
  - 3 unique patterns -> ~100.0

  **combineViralityScore:**
  - Components(hook=100, flow=100, value=100, trend=100) -> 100.0
  - Components(hook=0, flow=0, value=0, trend=0) -> 0.0
  - Components(hook=80, flow=60, value=70, trend=40) -> 80*0.35 + 60*0.30 + 70*0.25 + 40*0.10 = 28 + 18 + 17.5 + 4 = 67.5

  **rankClips with viralityScore:**
  - Clips with viralityScore [90, 70, 80] -> ranked [90, 80, 70] (sorted descending)
  - Existing overlap penalty still applies
