<task type="auto">
  <name>Task 2: Implement ASS subtitle file generation</name>
  <files>src/render/captions.nim</files>
  <action>
Add to src/render/captions.nim:

1. Import transcript/grouping for Caption type

2. formatASSTime proc: Convert milliseconds to ASS timestamp format (H:MM:SS.cc - centiseconds):
   - Example: 1234ms -> "0:00:01.23"

3. escapeASSText proc: Escape special ASS characters:
   - Backslash -> \\
   - Curly braces -> \{ and \}
   - Newlines -> \n

4. colorToASS proc: Convert hex color to ASS format (&HAABBGGRR):
   - "#ffffff" -> "&H00FFFFFF"
   - Note: ASS uses BGR order with alpha prefix

5. generateASSHeader proc(style: CaptionStyle, width, height: int): string
   - Generate [Script Info] section with PlayResX/PlayResY
   - Generate [V4+ Styles] section:
     - Format: Name, Fontname, Fontsize, PrimaryColour, SecondaryColour, OutlineColour, BackColour, Bold, Italic, Underline, StrikeOut, ScaleX, ScaleY, Spacing, Angle, BorderStyle, Outline, Shadow, Alignment, MarginL, MarginR, MarginV, Encoding
     - Alignment: 2=bottom-center, 5=center, 8=top-center (ASS spec)
     - Apply style settings to ASS style line

6. generateASSDialogue proc(caption: Caption, style: CaptionStyle, styleName: string): string
   - If highlightEnabled:
     - Build text with \k tags for each word: {\kDuration}word
     - Duration in centiseconds: (endMs - startMs) div 10
     - Use caption.words for timing
   - If speaker >= 0 and speakerColors enabled:
     - Override color with speaker color: {\c&HBBGGRR&}
   - Return: Dialogue: 0,startTime,endTime,styleName,,0,0,0,,text

7. generateASS proc(captions: seq[Caption], style: CaptionStyle, width, height: int): string
   - Combine header + [Events] section + all dialogue lines
   - Add Format line before Dialogue lines

8. writeASSFile proc(captions: seq[Caption], style: CaptionStyle, outputPath: string, width, height: int)
   - Generate ASS content and write to file (UTF-8, no BOM)
  </action>
  <verify>nim c --skipParentCfg --hints:off -o:nul src/render/captions.nim compiles without errors</verify>
  <done>ASS generation produces valid subtitle file with correct timing, karaoke tags for highlighting, and speaker colors</done>
</task>
