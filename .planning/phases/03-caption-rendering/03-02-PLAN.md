<task type="auto">
  <name>Task 1: Add FFmpeg filter string builders</name>
  <files>src/render/captions.nim</files>
  <action>
Add to src/render/captions.nim:

1. escapeFilterPath proc(path: string): string
   - Escape colons for FFmpeg filter syntax on Windows: "C:" -> "C\\:"
   - Escape backslashes: "\\" -> "\\\\"
   - Escape single quotes: "'" -> "\\'"
   - Return escaped path

2. buildASSFilter proc(assPath: string): string
   - Build FFmpeg ass filter string: "ass=filename='<escaped_path>'"
   - Use escapeFilterPath for the ASS file path
   - Example output: "ass=filename='C\\:/temp/captions.ass'"

3. buildDrawtextFilter proc(text: string, style: CaptionStyle, startMs, endMs: int64): string
   - Build FFmpeg drawtext filter for simple text overlay (no word highlighting)
   - Include:
     - fontfile=<escaped fontPath>
     - fontsize=<fontSize>
     - fontcolor=<color>
     - x=(w-text_w)/2 (center)
     - y position based on style.position:
       - cpBottomCenter: y=h-<marginBottom>
       - cpCenter: y=(h-text_h)/2
       - cpTopCenter: y=<marginTop>
     - borderw=<outlineWidth> if outline enabled
     - bordercolor=<outlineColor> if outline enabled
     - shadowx, shadowy, shadowcolor if shadow enabled
     - box=1, boxcolor=<boxColor>, boxborderw=<boxPadding> if backgroundBox enabled
     - text='<escaped text>'
     - enable='between(t,<startSec>,<endSec>)'
   - Escape text: single quotes, colons, backslashes

4. escapeDrawtextText proc(text: string): string
   - Escape for drawtext: ' -> \', : -> \:, \ -> \\, newline -> \\n
  </action>
  <verify>nim c --skipParentCfg --hints:off -o:nul src/render/captions.nim compiles without errors</verify>
  <done>FFmpeg filter string builders produce correctly escaped filter syntax</done>
</task>

<task type="auto">
  <name>Task 2: Implement caption burning integration with FFmpeg execution</name>
  <files>src/render/captions.nim</files>
  <action>
Add to src/render/captions.nim:

1. Import std/os for tempDir, joinPath
2. Import std/random for random temp filename
3. Import std/osproc for startProcess, waitForExit

4. CaptionBurnConfig object:
   - style: CaptionStyle
   - width, height: int (video dimensions)
   - useHighlight: bool (word-by-word reveal, default false)
   - tempDir: string (where to write ASS file, default system temp)

5. prepareCaptionFilter proc(captions: seq[Caption], config: CaptionBurnConfig): tuple[filter: string, tempFile: string]
   - Generate unique temp filename: joinPath(config.tempDir or getTempDir(), "honeyclip_captions_<random>.ass")
   - Generate ASS content using generateASS proc
   - Write ASS file to tempFile
   - Build filter string using buildASSFilter
   - Return (filter string, temp file path)
   - Caller is responsible for cleanup of temp file

6. cleanupCaptionTemp proc(tempFile: string)
   - Remove temp ASS file if it exists
   - Ignore errors (file may already be deleted)

7. burnCaptions* proc(inputPath, outputPath: string, captions: seq[Caption], config: CaptionBurnConfig, ffmpegPath: string = "ffmpeg"): int
   - Call prepareCaptionFilter to generate ASS file and filter string
   - Build FFmpeg command args:
     - "-i", inputPath
     - "-vf", filterString (the ass filter)
     - "-c:a", "copy" (copy audio unchanged)
     - "-y" (overwrite output)
     - outputPath
   - Execute FFmpeg via startProcess with poUsePath, poParentStreams options
   - Wait for process to complete with waitForExit
   - Call cleanupCaptionTemp to remove temp ASS file
   - Return FFmpeg exit code (0 = success)
  </action>
  <verify>nim c --skipParentCfg --hints:off -o:nul src/render/captions.nim compiles without errors</verify>
  <done>Caption burning integration generates ASS file and executes FFmpeg to burn captions into video</done>
</task>
