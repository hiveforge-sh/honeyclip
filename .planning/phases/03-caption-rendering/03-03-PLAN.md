<task type="auto">
  <name>Task 1: Add caption track to FCP7 XML export</name>
  <files>src/exports/fcp7.nim</files>
  <action>
Add to src/exports/fcp7.nim:

1. Import at top:
   - import ../transcript/grouping (for Caption type)
   - import ../render/captions (for CaptionStyle, getSpeakerColor)

2. Add helper proc hexToFCP7Color(hex: string): string
   - Convert "#RRGGBB" to FCP7 color format (normalized 0.0-1.0 RGB values)
   - Example: "#ff0000" -> "1.0 0.0 0.0"

3. Add proc addCaptionTrackFCP7(video: XmlNode, captions: seq[Caption], style: CaptionStyle, tb: int64, ntsc: string)
   - Create new video track for captions (after main video track)
   - For each caption:
     a. Create <clipitem> with unique id like "caption-{index}"
     b. Add timing:
        - start: caption.startMs converted to frames (ms * tb / 1000)
        - end: caption.endMs converted to frames
        - in: 0
        - out: duration in frames
     c. Add <generatoritem> with:
        - name: "Text"
        - effectid: "Text"
        - effectcategory: "Text"
        - effecttype: "generator"
     d. Add parameters:
        - str/Text: caption.text
        - fontname/Font: style.fontName
        - fontsize/Size: style.fontSize
        - textcolor/Fill Color: speaker color if speaker >= 0, else style.color
        - center/Center: position based on style.position
     e. If style.highlightEnabled and caption has words:
        - Add keyframe track for text color transition
        - Each word gets keyframe at its start time
        - Pre-word: secondary color (dimmed)
        - Active word: primary color (highlighted)
   - Track is enabled by default

4. Add proc fcp7_write_xml_with_captions*(name, output: string, resolve: bool, tl: v3, captions: seq[Caption], style: CaptionStyle)
   - Wrapper that calls existing fcp7_write_xml logic
   - Adds caption track before closing media element
  </action>
  <verify>nim c --skipParentCfg --hints:off -o:nul src/exports/fcp7.nim compiles without errors</verify>
  <done>FCP7 XML export includes caption track with text generator clips and timing</done>
</task>

<task type="auto">
  <name>Task 2: Add caption track to FCPXML export</name>
  <files>src/exports/fcp11.nim</files>
  <action>
Add to src/exports/fcp11.nim:

1. Import at top:
   - import ../transcript/grouping (for Caption type)
   - import ../render/captions (for CaptionStyle, getSpeakerColor)

2. Add helper proc hexToFCPXMLColor(hex: string): string
   - Convert "#RRGGBB" to FCPXML color string format
   - Example: "#ff0000" -> "1 0 0 1" (R G B A)

3. Add proc addCaptionTrackFCPXML(spine: XmlNode, captions: seq[Caption], style: CaptionStyle, tb: AVRational)
   - Create <gap> element as container for caption titles (to not displace video)
   - For each caption:
     a. Create <title> element with:
        - ref: reference to title format resource
        - name: truncated caption text (first 20 chars + "...")
        - offset: caption.startMs in FCPXML time format (frames/tb)
        - duration: (endMs - startMs) in FCPXML time format
     b. Add <param> elements for:
        - Text: caption.text
        - Position: based on style.position (0,0 for center, 0,-300 for bottom, etc.)
        - Flatten (text layout): 1
     c. Add <text-style> with:
        - font: style.fontName
        - fontSize: style.fontSize
        - fontColor: speaker color or style.color
     d. If style.highlightEnabled:
        - Use <text-style-def> with keyframed color for word timing

4. Add title format resource to resources section:
   - <effect id="title-effect" name="Custom Title" uid=".../Titles.localized/Custom/Custom.moti"/>

5. Add proc fcp11_write_xml_with_captions*(groupName, version, output: string, resolve: bool, tl: v3, captions: seq[Caption], style: CaptionStyle)
   - Wrapper that calls existing fcp11_write_xml logic
   - Adds caption gap/titles to spine
  </action>
  <verify>nim c --skipParentCfg --hints:off -o:nul src/exports/fcp11.nim compiles without errors</verify>
