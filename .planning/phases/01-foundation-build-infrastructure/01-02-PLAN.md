<task type="auto">
  <name>Task 1: Create libfacedetection FFI wrapper</name>
  <files>src/ml/facedetect.nim</files>
  <action>
    Create src/ml/facedetect.nim with FFI bindings for libfacedetection.

    Follow patterns from src/ffmpeg.nim:
    - Use `importc` with explicit header references
    - Define Nim wrapper types that hide raw pointers
    - Use `=destroy` hook for automatic cleanup

    Types to define:
    ```nim
    type
      FaceDetector* = object
        handle: pointer  # Opaque pointer to internal detector

      FaceRect* = object
        x*, y*: int
        width*, height*: int
        confidence*: float  # 0.0-1.0
        angle*: int  # Rotation angle in degrees
    ```

    C functions to import (from facedetectcnn.h):
    ```nim
    proc facedetect_cnn*(result_buffer: ptr cint, rgb_image_data: ptr uint8,
                        width, height, step: cint): ptr cint
        {.importc, header: "facedetectcnn.h".}
    ```

    Note: libfacedetection uses a buffer-based API, not object-based. The detector state is compiled into the library as static CNN weights.

    Nim wrapper procs to implement:
    ```nim
    proc detect*(image: ptr uint8, width, height, step: int): seq[FaceRect]
      ## Detect faces in BGR image data
      ## Returns sequence of detected face rectangles with confidence scores

    proc parseResults(buffer: ptr cint): seq[FaceRect]
      ## Parse the raw detection buffer into FaceRect sequence
      ## Buffer format: count, then for each face: x, y, w, h, neighbors, angle
    ```

    Memory management:
    - Allocate result buffer before detection (use alloc/dealloc with defer)
    - Buffer size: 0x9000 bytes (documented requirement)
    - Parse buffer into seq[FaceRect] before returning
  </action>
  <verify>
    - File compiles: `nim check src/ml/facedetect.nim`
    - Types are exported: grep for "FaceRect\*"
    - Memory cleanup uses defer: grep for "defer:"
  </verify>
  <done>
    src/ml/facedetect.nim provides type-safe face detection API with automatic buffer cleanup.
  </done>

<task type="auto">
  <name>Task 2: Create ONNX Runtime FFI wrapper</name>
  <files>src/ml/onnx.nim</files>
  <action>
    Create src/ml/onnx.nim with FFI bindings for ONNX Runtime C API.

    ONNX Runtime uses a C API with explicit status codes (not exceptions). Key patterns:
    - All functions return OrtStatus* (nil on success)
    - Objects are created via OrtApi function table
    - Cleanup via explicit Release functions

    Types to define:
    ```nim
    type
      OrtEnv* = object
        handle: pointer
      OrtSession* = object
        handle: pointer
      OrtValue* = object
        handle: pointer
      OrtMemoryInfo* = object
        handle: pointer

      OrtError* = object of CatchableError
        code*: int
    ```

    C types and functions to import:
    ```nim
    type
      OrtStatus {.importc, header: "onnxruntime_c_api.h".} = object
      OrtApiBase {.importc, header: "onnxruntime_c_api.h".} = object
      OrtApi {.importc, header: "onnxruntime_c_api.h".} = object

    proc OrtGetApiBase*(): ptr OrtApiBase
        {.importc, header: "onnxruntime_c_api.h".}
    ```

    The ONNX C API is accessed through a function table (OrtApi). Import the key functions:
    - CreateEnv, ReleaseEnv
    - CreateSession, ReleaseSession
    - CreateTensorWithDataAsOrtValue, ReleaseValue
    - Run (inference)

    Nim wrapper procs to implement:
    ```nim
    proc initOrtEnv*(name: string = "auto-editor"): OrtEnv
      ## Initialize ONNX Runtime environment (do this once at startup)

    proc loadModel*(env: OrtEnv, modelPath: string): OrtSession
      ## Load ONNX model from file path

    proc createTensor*(data: ptr float32, shape: openArray[int64]): OrtValue
      ## Create input tensor from float32 array

    proc run*(session: OrtSession, inputs: openArray[OrtValue],
              inputNames: openArray[string],
              outputNames: openArray[string]): seq[OrtValue]
      ## Run inference, returns output tensors

    proc `=destroy`*(env: var OrtEnv)
    proc `=destroy`*(session: var OrtSession)
    proc `=destroy`*(value: var OrtValue)
    ```

    Error handling:
    - Check OrtStatus after each API call
    - If not nil, extract error message and raise OrtError
    - Use `checkOrt()` helper proc to reduce boilerplate
  </action>
  <verify>
    - File compiles: `nim check src/ml/onnx.nim`
    - OrtSession type exported: grep for "OrtSession\*"
    - Error handling exists: grep for "OrtError"
    - Destructors defined: grep for "=destroy"
  </verify>
  <done>
    src/ml/onnx.nim provides ONNX Runtime wrapper with session management, tensor creation, and inference.
  </done>
</task>

<task type="auto">
  <name>Task 3: Create OpenCV FFI wrapper</name>
  <files>src/ml/opencv.nim</files>
  <action>
    Create src/ml/opencv.nim with minimal FFI bindings for OpenCV (core + imgproc only).

    OpenCV is C++ with a C API wrapper. Use the C API (opencv2/core/core_c.h) where possible,
    or importcpp for C++ types.

    Types to define:
    ```nim
    type
      Mat* = object
        handle: pointer  # cv::Mat*

      Size* = object
        width*, height*: int

      ColorConversion* = enum
        COLOR_BGR2RGB = 4
        COLOR_RGB2BGR = 4
        COLOR_BGR2GRAY = 6
        COLOR_RGB2GRAY = 7
    ```

    C++ functions to import via importcpp:
    ```nim
    type
      CvMat {.importcpp: "cv::Mat", header: "opencv2/core.hpp".} = object
        rows: cint
        cols: cint
        data: ptr uint8

    proc newMat(): CvMat {.importcpp: "cv::Mat()", constructor.}
    proc newMat(rows, cols, type: cint): CvMat {.importcpp: "cv::Mat(@)", constructor.}
    proc release(m: var CvMat) {.importcpp: "#.release()".}
    proc clone(m: CvMat): CvMat {.importcpp: "#.clone()".}
    ```

    Import resize and cvtColor:
    ```nim
    proc cvResize(src, dst: CvMat, dsize: tuple[width, height: cint],
                  fx, fy: cdouble, interpolation: cint)
        {.importcpp: "cv::resize(@)", header: "opencv2/imgproc.hpp".}

    proc cvCvtColor(src, dst: CvMat, code: cint)
        {.importcpp: "cv::cvtColor(@)", header: "opencv2/imgproc.hpp".}
    ```

    Nim wrapper procs:
    ```nim
    proc createMat*(width, height: int, channels: int = 3): Mat
      ## Create empty Mat with given dimensions

    proc fromBuffer*(data: ptr uint8, width, height: int, channels: int = 3): Mat
      ## Wrap existing buffer as Mat (no copy)

    proc resize*(src: Mat, newWidth, newHeight: int): Mat
      ## Resize image, returns new Mat

    proc cvtColor*(src: Mat, conversion: ColorConversion): Mat
      ## Convert color space, returns new Mat

    proc data*(m: Mat): ptr uint8
      ## Get raw data pointer

    proc `=destroy`*(m: var Mat)
      ## Release Mat memory
    ```

    Memory management:
    - Mat owns its data by default
    - fromBuffer creates a view (caller must keep buffer alive)
    - All returned Mats are new copies
  </action>
  <verify>
    - File compiles: `nim check src/ml/opencv.nim`
    - Mat type exported: grep for "Mat\*"
    - resize and cvtColor exported
    - C++ imports use importcpp: grep for "importcpp"
  </verify>
  <done>
    src/ml/opencv.nim provides minimal OpenCV wrapper for image resizing and color conversion.
  </done>
