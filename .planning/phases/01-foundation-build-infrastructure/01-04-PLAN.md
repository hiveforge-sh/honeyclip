<task type="auto">
  <name>Task 2: Add binary size validation to CI</name>
  <files>.github/workflows/build.yml</files>
  <action>
    Add step to validate binary sizes after ML build:

    ```yaml
    - name: Validate binary sizes
      run: |
        echo "=== ML Library Sizes ==="
        du -sh build/lib/libfacedetection.a || true
        du -sh build/lib/libopencv_*.a || true
        du -sh build/lib/libonnxruntime.a || true

        echo "=== Total Size ==="
        TOTAL=$(du -s build/lib/*.a 2>/dev/null | awk '{sum += $1} END {print sum}')
        TOTAL_MB=$((TOTAL / 1024))
        echo "Total ML library size: ${TOTAL_MB}MB"

        # Soft limit: 50MB
        if [ "$TOTAL_MB" -gt 50 ]; then
          echo "::warning::ML libraries exceed 50MB soft limit (${TOTAL_MB}MB)"
        fi

        # Hard limit: 100MB
        if [ "$TOTAL_MB" -gt 100 ]; then
          echo "::error::ML libraries exceed 100MB hard limit (${TOTAL_MB}MB)"
          exit 1
        fi
    ```

    Also add final binary size check after compile step:
    ```yaml
    - name: Check final binary size
      run: |
        SIZE=$(stat -f%z honeyclip 2>/dev/null || stat -c%s honeyclip)
        SIZE_MB=$((SIZE / 1024 / 1024))
        echo "Final binary size: ${SIZE_MB}MB"

        if [ "$SIZE_MB" -gt 100 ]; then
          echo "::error::Final binary exceeds 100MB limit"
          exit 1
        fi
    ```
  </action>
  <verify>
    - Size validation step exists: grep for "Validate binary sizes" in build.yml
    - Hard limit enforced: grep for "100MB" in build.yml
    - CI warnings configured: grep for "::warning::" in build.yml
  </verify>
  <done>
    CI validates ML library sizes against 50MB soft limit and 100MB hard limit.
  </done>
</task>
