       a. Check if cache is valid using `shouldRebuild()` proc (compare SHA256 with cached value)

          - Download source with curl

    4. Print progress: "[{name}] Configuring...", "[{name}] Building...", "[{name}] Installing..."

    Implement helper procs:
    - `shouldRebuild(package: Package, buildPath: string): bool` - check if rebuild needed
    - `writeCacheMetadata(package: Package, buildPath: string)` - write JSON cache file
    - `onnxBuild(buildPath: string, crossWindows: bool)` - special ONNX build handling

    For ONNX Runtime, use subprocess to call build.sh with flags:
    ```
    ./build.sh --config MinSizeRel --minimal_build extended --disable_ml_ops --build_shared_lib OFF --parallel $(nproc)
    ```

    Create ml_sources/.gitkeep to track the directory in git.
