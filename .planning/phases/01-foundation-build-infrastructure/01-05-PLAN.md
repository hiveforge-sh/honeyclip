<task type="auto">
  <name>Task 1: Fix ONNX Runtime static linking configuration</name>
  <files>ae.nimble</files>
  <action>
    Change the ONNX Runtime buildArguments from:
    ```nim
    "--build_shared_lib",
    ```
    to:
    ```nim
    "--build_shared_lib", "OFF",
    ```

    This disables shared library building and ensures ONNX Runtime produces static libraries (libonnxruntime.a)
    as required by the phase success criteria.

    Location: ae.nimble line 245 (inside the onnxruntime Package definition)

    Why: The original configuration passes "--build_shared_lib" to build.sh without the "OFF" argument,
    which means it defaults to building a shared library. For static linking (goal #2), we need to
    explicitly disable shared library building.
  </action>
  <verify>
    grep -A 10 "let onnxruntime = Package" ae.nimble | grep -E '"--build_shared_lib", "OFF"'
    Should find the line with both the flag and "OFF" argument.
  </verify>
  <done>ONNX Runtime configured for static library output (--build_shared_lib OFF)</done>
</task>
