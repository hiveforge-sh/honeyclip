## Tech Debt Summary

### Phase 1: Foundation (Non-blocking)

**ML Library Size:** 114MB total exceeds 100MB hard limit
- OpenCV: 81MB (includes extra modules: calib3d, features2d, flann)
- ONNX Runtime: 31MB
- libfacedetection: 0.4MB

**Remediation options:**
1. Strip debug symbols from libraries
2. Use -Os optimization instead of -O2
3. Investigate which objdetect features pull in calib3d
4. Consider removing unused OpenCV modules

**Impact:** Build size larger than target, no functional impact.

### Phase 5: Engagement Scoring (Enhancement deferred)

**Custom hook JSON loading:** Built-in patterns work, custom loading from file not implemented.

**Impact:** Users cannot add custom hook detection patterns. Built-in patterns (question, challenge, story, list, promise) cover common cases.

### Phase 7: Speaker Reframing (Documentation)

**Missing unit tests:** Kalman filter, assignment algorithm, and tracker modules lack dedicated tests.
- Compositor tests exist (12 tests)
- Embedding tests exist (8 tests, conditional on enable_ml)
- Implementation manually tested and working

**Windows limitation:** ML features stubbed due to LTO issues. Falls back to center crop.

**Impact:** Lower test coverage on tracking internals, documented Windows limitation.
